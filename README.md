<h1>Chesss — Simple Chess Project</h1>

<h2>About / О проекте</h2>
<p>
This is a simple educational chess project created to demonstrate basic chess logic,
game structure, and move handling.
</p>
<p>
Это простой учебный проект по шахматам, созданный для демонстрации базовой логики игры,
структуры проекта и обработки ходов.
</p>

<h2>Getting Started / Запуск проекта</h2>
<p>Clone the repository and run the main file:</p>
<pre><code>git clone https://github.com/it-withend/chesss.git
cd chesss
python main.py</code></pre>

<p>
Если точка входа отличается, запустите основной файл проекта.
</p>
