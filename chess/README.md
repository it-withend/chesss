# ♟️ Шахматы - Полнофункциональная игра

Полнофункциональная шахматная игра с ИИ, анимациями, звуками и всеми современными функциями.

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-2.5.2-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

## ✨ Возможности

### 🎮 Основной функционал
- ✅ **Полные правила шахмат**: все фигуры, рокировка, превращение пешки, шах, мат
- ✅ **Валидация ходов**: проверка всех правил, включая защиту от шаха
- ✅ **Визуальная обратная связь**: подсветка возможных ходов, атакованных фигур, шаха
- ✅ **Защита короля**: король не может быть взят

### 🤖 Игровые режимы
- ✅ **Игра против ИИ**: 3 уровня сложности (легкий, средний, сложный)
- ✅ **Выбор сложности**: меню для выбора уровня ИИ
- ✅ **Таймеры**: контроль времени для каждого игрока

### 🎨 Визуальные эффекты
- ✅ **Классическая доска**: деревянная текстура, традиционные цвета
- ✅ **Подсветка ходов**: зеленые кружки для возможных ходов, красные для атак
- ✅ **Подсветка последнего хода**: желтая подсветка
- ✅ **Индикация шаха**: красная подсветка короля под шахом
- ✅ **Анимации**: плавное движение фигур при ходе
- ✅ **Изображения фигур**: поддержка загрузки изображений из интернета
- ✅ **Unicode символы**: красивые шахматные символы как резервный вариант

### 🔊 Звуковые эффекты
- ✅ Звук хода
- ✅ Звук взятия фигуры
- ✅ Звук шаха
- ✅ Звук мата

### 🖥️ Интерфейс
- ✅ **Панель информации**: текущий ход, таймеры, статус игры
- ✅ **История ходов**: отображение последних 10 ходов в нотации
- ✅ **Рабочие кнопки**:
  - Новая игра
  - Выбор сложности ИИ
  - Отменить ход
  - Сохранить игру
  - Загрузить игру

### 💾 Дополнительные функции
- ✅ **Сохранение/загрузка**: сохранение партий в JSON
- ✅ **Анализ позиции**: оценка позиции для ИИ
- ✅ **Минимакс алгоритм**: продвинутый ИИ для сложного уровня

## 🚀 Быстрый старт

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone <your-repo-url>
cd chess
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите игру:**
```bash
python chess_game.py
```

### (Опционально) Загрузка ресурсов

Для улучшенной графики загрузите изображения фигур:
```bash
python download_resources.py
```

**Примечание**: Игра полностью работает и без загруженных ресурсов, используя Unicode символы для фигур.

## 📦 Сборка .exe файла

### Windows:
```bash
build_chess.bat
```

### Вручную:
```bash
pyinstaller --onefile --windowed --name=Шахматы --add-data "pieces;pieces" --add-data "sounds;sounds" chess_game.py
```

Готовый .exe будет в папке `dist/Шахматы.exe`

## 🎮 Управление

### Мышь:
- **Левый клик** на фигуру - выбрать фигуру
- **Левый клик** на подсвеченную клетку - сделать ход
- **Левый клик** на кнопки в правой панели - действия

### Клавиатура:
- Игра полностью управляется мышью

## 🤖 ИИ противник

ИИ имеет 3 уровня сложности:

1. **Легкий**: случайные ходы
2. **Средний**: выбирает лучший ход по оценке позиции
3. **Сложный**: использует минимакс алгоритм с глубиной 2

Выбор сложности доступен через кнопку "Сложность ИИ" в правой панели.

## 🎨 Добавление своих ресурсов

### Изображения фигур:
Поместите PNG файлы в папку `pieces/` с именами:
- `white_king.png`, `white_queen.png`, и т.д.
- `black_king.png`, `black_queen.png`, и т.д.

Размер: рекомендуется 150x150 пикселей или больше (игра автоматически масштабирует).

### Звуки:
Поместите WAV файлы в папку `sounds/`:
- `move.wav` - звук хода
- `capture.wav` - звук взятия
- `check.wav` - звук шаха
- `checkmate.wav` - звук мата
